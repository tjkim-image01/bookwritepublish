# 그림책 서재

성경 이야기 어린이 그림동화 3D 뷰어 (Three.js). 책을 눌러 펼치고, 넘기면 글이 있는 쪽은 자동으로 읽어 줍니다.

| 주소 | 내용 |
|------|------|
| `/` | 버전 안내 |
| `/v1/` | PC·태블릿 — 펼침면 보기 (오른쪽 누르면 다음 장, 왼쪽 누르면 앞 장) |
| `/v2/` | 모바일 대응 — 세로 화면은 한 쪽씩 크게, 좌우로 밀어 넘김 |
| `/v3/` | 팝업북 — 펼치면 오려 낸 그림이 일어섬 (팝업북 책장만) |
| `/res/books/` | v1·v2 가 함께 쓰는 책 데이터 (쪽 그림·낭독·book.json) |
| `/res/books-popup/` | v3 팝업북 데이터 (쪽 그림·레이어·낭독·book.json) |

공용 리소스는 `res/`에 모읍니다. `res/bookshelf/`는 여러 책장 디자인을 위한 폴더이며, 디자인별 하위 폴더를 추가해 관리합니다. v1·v2·v3에서 보물 부두, 갑판 도서관, 해골섬 트레일(기본)을 선택할 수 있으며 선택은 브라우저에 저장됩니다.

모바일 주소창 숨기기: 뷰어는 스크롤이 없는 3D 화면이라 주소창이 저절로 접히지 않습니다. `res/fullscreen.js`가 안드로이드·iPad에서는 처음 누를 때 전체 화면으로 바꾸고(직접 빠져나오면 왼쪽 위 버튼으로 다시), 아이폰 사파리에서는 '홈 화면에 추가' 안내를 보여 줍니다. 각 폴더의 `manifest.webmanifest`(display: fullscreen) 덕분에 홈 화면 아이콘으로 열면 주소창 없이 열립니다.

- 이 저장소는 비공개 제작 저장소 `bookwrite` 의 `web/` 폴더를 그대로 올린 것입니다. 여기서 직접 고치지 마세요.
- 로컬 실행: `web/bin/start.sh` → http://localhost:8710/
